# 🛍️ Shopping Application

A modern and responsive shopping website built using **React.js**.  
This project demonstrates a frontend e-commerce application with product collections, promotional deals, and a clean shopping interface.

## 🚀 Features

- 🏠 Modern shopping homepage
- 👗 Women's fashion collection
- 👔 Men's fashion collection
- 🧸 Children's collection
- 💄 Beauty products section
- 🔥 Deal of the Hour section
- ⏱️ Live countdown timer
- 🛒 Add to Cart buttons
- ❤️ Product wishlist UI
- 🖼️ Product images
- 📱 Responsive design
- ✨ Smooth animations and hover effects

## 🛠️ Technologies Used

- **React.js**
- **JavaScript**
- **HTML5**
- **CSS3**
- **Create React App**
- **Git & GitHub**
